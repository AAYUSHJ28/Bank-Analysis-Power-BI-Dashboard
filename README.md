# Bank Analysis Power BI Dashboard
## Overview
This Power BI project provides insights into the financial and demographic characteristics of bank customers. The analysis includes key performance indicators (KPIs), customer segmentation, and trend analysis to help stakeholders understand customer behavior and balance trends.

Data Sources
The project uses synthetic or anonymized customer and financial data, structured across the following tables:

Bank Data: Contains account balances, demographic information, and account ownership details.
Date Table: Enables time-based filtering and trends analysis.
Dim Data: Dimensional data for customer segmentation.
Measures: Calculated metrics like average balance and MoM growth rates.
How to Use
Filters:
Use slicers for demographics (e.g., gender, education, marital status) to customize the visuals.
State-based and job classification filters provide regional and professional insights.
Interactivity:
Hover over charts for detailed tooltips.
Drill through for deeper insights into specific customer segments.
Customization:
Add or remove fields from the visuals as needed.
Customize KPIs and add drill-through fields for additional analyses.
Key Insights and Recommendations
Gender Disparity: Male customers have slightly higher balances than females.
Regional Focus: California and Nevada are key states with high total balances.
Customer Growth: Positive growth in both customer base and balances indicates steady bank performance.
Education Impact: Secondary education dominates customer segments, suggesting potential campaigns targeted at tertiary-level customers.
Marital Insights: Married customers have the highest balances, offering cross-selling opportunities.
